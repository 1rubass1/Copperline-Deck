# Changelog

All notable changes to Copperline Deck will be documented here.

## [0.1.0-dev] - 2026-10-06

### Added

- Initial extracted development snapshot.
- Windows launcher source.
- PowerShell server manager and command channel.
- WebView2 log surface with PixiJS visual effects.
- Particle network and right-edge caustic light effect.
- Automatic rendering pause when minimized, hidden, or fully occluded.
- Floating scroll-to-bottom control.
- Reproducible dependency bootstrap, build, and packaging scripts.
- Initial architecture and development documentation.

### Changed

- Project-facing branding changed from the original server-specific shell to Copperline Deck.
- Server-specific runtime data, mods, worlds, logs, caches, and binaries are excluded from source control.
