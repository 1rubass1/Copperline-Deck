# Security

Copperline Deck can execute Minecraft server console commands and launch local processes. Treat configuration files and future remote-control features as security-sensitive.

## Reporting

If GitHub private vulnerability reporting is enabled for this repository, use it for security issues. Avoid publishing credentials, tokens, private server addresses, or exploit details in public issues.

## Current scope

The current development snapshot is intended for local Windows use. No remote authentication boundary is provided by Copperline Deck itself.
