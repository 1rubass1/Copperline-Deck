# Roadmap

## 0.1 — Extract the working application

Status: **in progress**

- Preserve the proven desktop shell and rendering behavior.
- Remove server data and generated binaries from source control.
- Introduce reproducible dependency bootstrap and build scripts.
- Establish `development`, `release`, and `main` branches.

## 0.2 — Decouple server profiles

- Separate application root from Minecraft server root.
- Make Java executable configurable.
- Make server jar and launch arguments configurable.
- Make memory limits configurable.
- Make port detection profile-aware.
- Move runtime state to an application data directory.
- Support adding an existing server without modifying its directory layout.

## 0.3 — Refactor runtime boundaries

- Move configuration parsing into a dedicated module.
- Move process management into a dedicated module.
- Define a stable host-to-WebView message contract.
- Replace remaining project-specific naming.
- Add structured diagnostics.

## 0.4 — Productize the client

- First-run profile setup.
- Server profile selector.
- Localization layer.
- Theme/visual settings.
- Better failure states and recovery.
- Signed/packaged Windows distribution.

## 1.0 — First public release

- Stable server-profile format.
- Upgrade/migration strategy.
- Release artifacts generated by CI.
- User-facing documentation.
- License finalized.
- Security and contribution policy finalized.
